El Legado de Tim Bergling

De Estocolmo para el mundo

Tim Bergling, mundialmente conocido como Avicii, fue un productor y DJ sueco que revolucionó la música electrónica (EDM) mezclándola con elementos acústicos, country y pop, creando melodías inolvidables.
